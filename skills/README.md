# Skills

把 Codex 风格的 Skill（`SKILL.md` / `SKILL.cn.md`，可选 `meta.yaml` 和 `references/`）放到这里，
`MiniMax H3 Multimodal Chat` 节点即可在 `skill` 下拉框中加载。

当前内置：

- `h3-prompt-writing`：H3 通用视频提示词编写（英文输出）
- `h3-prompt-writing-CN`：H3 通用视频提示词编写（中文主体，固定写法保持英文）
- `Singularity-h3-prompt-writing-EN`：全参考图生视频高级规范（英文输出）
- `Singularity-h3-prompt-writing-CN`：全参考图生视频高级规范（中文主体，固定写法保持英文）

本插件同时会自动发现 `custom_nodes/comfyUI-llama-TE/skills` 下的 Skill。
